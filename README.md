# Netflix Content Analytics Dashboard – Task 13

## 1. Project Overview

This project focuses on analyzing the Netflix content dataset using **Tableau Public**. The dashboard explores the distribution of movies and TV shows, content release trends, ratings, and country-wise content availability.

The main objective is to identify meaningful patterns and business insights through interactive data visualization.

## 2. Objective

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify trends in Netflix content releases over the years.
- Understand the distribution of content across different ratings.
- Compare Netflix content availability across countries.
- Create an interactive dashboard using Tableau Public.

## 3. Tools and Technologies Used

- **Tableau Public** – Data visualization and dashboard creation.
- **Netflix Dataset (CSV)** – Dataset used for analysis.
- **GitHub** – Project documentation and submission.

## 4. Visualizations Created

The dashboard contains four visualizations:

1. **Content Type Distribution:** Compares the number of Movies and TV Shows available in the dataset.
2. **Netflix Releases by Year:** Displays the yearly trend of Netflix content releases using a line chart.
3. **Netflix Content by Rating:** Shows how content is distributed across different age and maturity ratings.
4. **Netflix Content by Country:** Compares the number of Netflix titles across different countries using a horizontal bar chart.

## 5. Interactive Filters

A Release Year filter was added to the dashboard.

This allows users to select a particular year range and explore how the visualizations change based on the selected period.

## 6. Key Findings

1. Movies account for a significantly larger share of the Netflix catalog than TV Shows.
2. Netflix content releases increased considerably over the years, with a major rise during the late 2010s.
3. The TV-MA rating represents the largest category in the content rating visualization, followed by TV-14.
4. The United States has the highest number of titles in the country-wise analysis, followed by India and the United Kingdom.
5. The dashboard highlights differences in content distribution across release years, ratings, and countries.

## 7. Suggestions

1. Netflix can continue expanding its TV Show catalog to improve the balance between Movies and TV Shows.
2. The platform can explore opportunities to produce more regional and international content.
3. Content recommendations can be tailored to different audience age groups based on rating categories.

## 8. Recommendations

1. Analyze country-wise content distribution to identify opportunities for regional content expansion.
2. Monitor yearly content release trends to support future content planning.
3. Use rating-based analysis to understand the variety of content available for different audience groups.

## 9. Conclusion

The Netflix Content Analytics Dashboard provides a clear overview of the platform's content distribution, release trends, ratings, and country-wise availability. The analysis shows that Movies form the largest content category, the United States contributes the highest number of titles, and content releases increased significantly during the late 2010s.

The interactive Tableau dashboard makes it easier to explore these patterns using the Release Year filter. Overall, this project demonstrates how data visualization can transform a dataset into meaningful business insights and support better content planning and decision-making.
